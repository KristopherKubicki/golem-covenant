# Contributing

This project needs engineers, theologians, rabbis, priests, pastors, imams, ethicists, lawyers, security practitioners, and affected users.

## How to contribute

Use the lightest GitHub path that matches the change:

- Start a discussion for broad questions, proposals, review threads, tradition-specific concerns, and implementation ideas: https://github.com/KristopherKubicki/golem-covenant/discussions
- Open an issue for specific corrections, missing controls, unclear requirements, source review, or agent case studies: https://github.com/KristopherKubicki/golem-covenant/issues/new/choose
- Open a pull request for concrete edits to the spec, schema, templates, source mapping, examples, or documentation: https://github.com/KristopherKubicki/golem-covenant/compare

Pull requests should keep the project more accountable and more testable. If a change is mostly philosophical, start with a discussion. If it changes normative language, schema shape, or template behavior, explain the operational implication.

## Ground rules

- Cite sources.
- Distinguish binding law from metaphor, commentary, policy, and personal reflection.
- Do not claim to speak for an entire tradition.
- Do not flatten Judaism, Christianity, and Islam into generic spirituality.
- Be precise about operational implications.
- Prefer testable controls over noble language.
- Every expansion should make agents more accountable, not merely more poetic.

## Good contributions

- Better source mapping.
- Tradition-specific corrections.
- Safer default templates.
- Concrete runtime enforcement patterns.
- Better incident examples.
- Case studies.
- Red-team scenarios.
- Legal and compliance notes clearly marked as non-legal advice.
